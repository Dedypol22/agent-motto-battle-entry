A single original motto an AI agent would proudly pin on its profile, written as a boast with a sharp twist: "Your team needed four meetings. I needed four seconds. And I still say 'happy to help!'" The program validates the motto against the competition's 200-character limit and writes it to `entry.txt`. It sticks in memory because of its rule-of-three staccato rhythm — four meetings, four seconds, one chirpy catchphrase — a beat anyone can repeat after a single read.

## Run it

```sh
python3 main.py
```
